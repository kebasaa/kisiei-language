# Archives

Le dossier [`archive/`](https://github.com/kebasaa/kisiei-language/tree/main/archive) du dépôt conserve des documents anciens sur le kisiei : ceux sur lesquels s'appuie ce guide, et d'autres sources (lexiques, textes, listes de termes) qui restent à exploiter. Ce sont pour la plupart des tapuscrits numérisés, antérieurs à l'orthographe actuelle : ils ne servent pas de modèle d'orthographe, et tout ce qu'on en tire est vérifié dans la Bible.

## Comment citer le manuel de 1979

Les numéros de page cités (« Keita 1979, p. 57 ») sont ceux du **tapuscrit**. Dans la transcription, chaque page commence par un lien vers les notes manuscrites de cette page (« ✎ Handwritten notes, p. 57 »), ce qui permet de retrouver le passage.

L'orthographe des citations de 1979 est celle de l'original (*tyo*, *nh*, *è*, *ö*…) ; la page [Ancienne et nouvelle orthographe](../orthography/old-and-new.md) explique comment la lire.
