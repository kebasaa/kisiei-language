# Sources

Ce guide s'appuie sur trois ensembles de sources, dans cet ordre d'autorité :

1. **La Bible en kisiei** [[(BKG)]], norme de l'orthographe et de l'usage ;
2. **le manuel de Keita** [[Keita1979|(Keita 1979)]] et ses annotations manuscrites, description de base de la grammaire ;
3. **la grammaire et le dictionnaire de Childs** [[Childs1995|(Childs 1995]], [[Childs2000|2000)]], description du kissi du Sud, pour la comparaison.

La page [Sources et norme](../introduction/sources.md) explique ce choix.

- [Bibliographie](bibliography.md) : toutes les références citées ;
- [Archives](archive.md) : les documents conservés dans le dépôt ;
- [Outils](tools.md) : la liste des mots de la Bible, la concordance et les vérifications automatiques.
