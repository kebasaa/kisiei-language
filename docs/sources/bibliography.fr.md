# Bibliographie

Les références citées dans le guide, par ordre alphabétique d'auteur. Les citations du type « (Keita 1979, p. 57) » renvoient à cette liste ; les références bibliques (« Gn 1,3 ») renvoient au verset correspondant de la Bible en kisiei sur bible.com.

Les travaux de l'Académie des Langues et les mémoires de l'Institut polytechnique de Conakry cités en 1979 (Tolno, Sow, Kamano, Camara, Iffono) n'ont pas pu être consultés ; ils sont donnés d'après la bibliographie de [[Keita1979]].
