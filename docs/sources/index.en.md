# Sources

This guide relies on three sets of sources, in this order of authority:

1. **The Kisiei Bible** [[(BKG)]], the standard for spelling and usage;
2. **Keita's manual** [[Keita1979|(Keita 1979)]] and its handwritten annotations, the basic description of the grammar;
3. **Childs's grammar and dictionary** [[Childs1995|(Childs 1995]], [[Childs2000|2000)]], a description of Southern Kissi, for comparison.

The [Sources and the standard](../introduction/sources.md) page explains this choice.

- [Bibliography](bibliography.md): all the references cited;
- [Archive](archive.md): the documents kept in the repository;
- [Tools](tools.md): the list of Bible words, the concordance and the automatic checks.
