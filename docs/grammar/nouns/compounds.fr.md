# Noms composés

Le kisiei forme beaucoup de noms nouveaux en associant deux mots ou plus. On en distingue huit types [[(Keita1979, p. 31-33)]] ; la Bible [[(BKG)]] en fait un usage considérable pour les notions nouvelles.

## Types de composés

| Type | Exemple de 1979 (réécrit) | Exemple (Bible) | Sens |
| --- | --- | --- | --- |
| nom + nom | {{mɔmɔtɔmndo\|r}} « fruit dont les singes raffolent » (riz + singe) | {{fuɲa-mamaa}} | ancêtre (père + grand-parent) |
| nom + verbe | {{peekolaa\|r}} « puits » (eau + boire) | {{ɲɛdiaa}} | nourriture (chose + manger) |
| nom + adjectif | {{naasiaŋaa\|r}} « lèpre » (maladie + rouge) | {{kɔlvesɛiyo}} | violence, méchanceté (cœur + sec, dur) |
| nom + verbe + négation | {{tɔmcilon\|r}} « variété de maïs » (singe + voir + pas) | | |
| nom + référent + nom | {{kelamaɲumndan\|r}} « promenade nocturne » | | |
| nom + mot de liaison + nom | {{cɔwlabaa\|r}} « bagarre » (guerre + de + main) | | |

## Composés de la Bible

La Bible crée de nombreux composés pour les réalités religieuses, juridiques ou techniques. Ils sont presque toujours écrits **avec traits d'union** entre leurs parties :

| Composé | Parties | Sens |
| --- | --- | --- |
| {{vana-solia-lasálàá}} | personne + qui offre + sacrifice | prêtre [[GEN.41.45]] |
| {{fonda-loamaa-lasálàá}} | lieu + brûler + sacrifice | autel [[GEN.8.20]] |
| {{vana-tɛɛngaa-diom}} | personne + entre + parole | prophète [[GEN.20.7]] |
| {{vanaa-mangalaa-isɔɔa}} | personnes + … | peuples, nations [[GEN.12.2]] |
| {{cɛi-kola}} | maison + toile | tente [[GEN.9.21]] |
| {{fuɲa-mamaa}} | père + grand-parent | ancêtre [[GEN.17.4]] |

Les composés anciens et très courants s'écrivent **en un seul mot** :

| Composé | Parties | Sens |
| --- | --- | --- |
| {{vanapɔnɔɔ}} | personne + mâle | homme |
| {{vanalanɔɔ}} | personne + femelle | femme |
| {{vanacieo}} | personne + village | être humain |
| {{ɲɛdiaa}} | chose + manger | nourriture |
| {{halataalaa}} | (Dieu, ciel) + … | ciel |

!!! rule "Règle d'écriture"
    - Un composé **figé et courant** s'écrit en un seul mot ({{vanapɔnɔɔ}}).
    - Un composé **descriptif**, dont chaque partie garde son sens, s'écrit avec **traits d'union** ({{vana-solia-lasálàá}}).
    - Le premier élément est à la **forme radicale** ({{fuɲa}}-, non *fuɲaa*-) ; seul le dernier porte la terminaison de classe et le pluriel ({{vanaa-solia-lasálàá}} « les prêtres »).

## Noms propres composés

On trouve aussi des prénoms composés du prénom de rang et d'un événement lié à la naissance [[(Keita1979, p. 32)]] : *Tamba lɔɔ* « Tamba né le jour du marché », *Saa muuloo* « Saa né pendant la période des impôts ».
