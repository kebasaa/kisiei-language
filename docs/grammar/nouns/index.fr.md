# Le nom

Le nom kisiei se compose d'un **radical** et d'une **terminaison de classe**. La classe détermine le pluriel du nom et la forme de tous les mots qui s'accordent avec lui.

- [Classes nominales](noun-classes.md) : les terminaisons, la forme pleine et la forme radicale ;
- [Pluriel](plural.md) : comment passer du singulier au pluriel ;
- [Noms composés](compounds.md) : nom + nom, nom + verbe, composés de la Bible ;
- [Dérivation](derivation.md) : suffixes *-nɔɔ*, *-yɛi*, *-ndɔɔ*, préfixes issus de noms, redoublement.

L'accord des autres mots avec le nom est décrit à la page [Accord](../agreement.md).
