# Pluriel

Le pluriel se forme en **remplaçant la terminaison du singulier** par une terminaison de pluriel. Quelle terminaison ? Cela dépend de la classe du nom et, pour la classe *o / a / ɔ*, de ce que le nom désigne [[(Keita1979, p. 26-29)]]. Toutes les paires ci-dessous sont attestées dans la Bible [[(BKG)]].

## Règles

### Personnes et animaux : -a

Les noms de personnes et d'animaux en *-o*, *-ɔ* ou *-a* font leur pluriel en **-a** (*-nda* après une nasale, *-la* après *l*, *-va* après *w*) :

| Singulier | Pluriel | Sens |
| --- | --- | --- |
| {{nawvo}} | {{nawva}} | vache(s) |
| {{yowvo}} | {{yowva}} | oiseau(x) |
| {{kɛwvo}} | {{kɛwva}} | serpent(s) |
| {{cuinndo}} | {{cuinnda}} | chèvre(s) |
| {{miallo}} | {{mialla}} | étranger(s) |
| {{vanndo}} | {{vannda}} | personne(s) |
| {{pɔmbɔɔ}} | {{pɔmbɔa}} | cadet(s) |
| {{poo}} | {{poaa}} | fils |
| {{lanɔɔ}} | {{laandua}} | femme(s), épouse(s) |
| {{cuaa}} | {{cuavaa}} | enfant(s) |

### Choses en -o, -a, -ɔ : -lan

Les noms de choses en *-o*, *-ɔ* ou *-a* font leur pluriel en **-lan** (*-tan* après *l*, *-ndan* après une nasale) :

| Singulier | Pluriel | Sens |
| --- | --- | --- |
| {{kobio}} | {{kobilan}} | ville(s) |
| {{domaa}} | {{domalan}} | chemise(s), vêtement(s) |
| {{naa}} | {{naalan}} | maladie(s) |
| {{paa}} | {{paalan}} | os |

### Classe i : -on, -ɔn, -an

Les noms en *-ei* font leur pluriel en **-on** ; ceux en *-ɛi*, en **-ɔn** [[(Keita1979, p. 27-28)]] :

| Singulier | Pluriel | Sens |
| --- | --- | --- |
| {{pelei}} | {{pelon}} | pied(s) |
| {{suei}} | {{suon}} | doigt(s) |
| {{mɔɛi}} | {{mɔɔn}} | couteau(x) |
| {{sɔɛi}} | {{sɔɔn}} | parole(s) |
| {{kelɛi}} | {{kelan}} | bracelet(s) — exception en *-an* |

### Classe e : -on

| Singulier | Pluriel | Sens |
| --- | --- | --- |
| {{yɛiye}} | {{yɛiyon}} | semence(s) |
| *kulle* | {{kullon}} | graine(s) |

### Classe len : -an, -lan, -tan

| Singulier | Pluriel | Sens |
| --- | --- | --- |
| {{nilen}} | {{nilan}} | oreille(s) |
| {{bollen}} | {{bóltan}} | tête(s) |
| *pelten* [[(Keita1979, p. 28)]] | {{peltan}} | œuf(s) |

### Exceptions

Les exceptions suivantes figurent dans la description de 1979 [[(Keita1979, p. 27)]] :

- *-o* → *-e* : *kollo / kolle* « noix de cola », *hollo / holle* « champignon ».
- *-o* → *-on* : {{cieo}} / {{cieon}} « village(s) », *kilio / kilion*.
- Invariables : {{saa}} « mouton(s) », *yangaa* « crevette(s) », {{ɲinaa}} « esprit(s), démon(s) ».

## Noms sans pluriel

- Les **masses et les liquides** ne s'emploient qu'au singulier : {{hɛlle}} « sel », {{mɛnndan}} « eau ».
- Les **noms abstraits** non plus : {{diolan}} « nom », {{hangullo}} « chaleur », {{ɲumndan}} « obscurité ».
- Certains **collectifs** n'existent qu'au pluriel : {{diallon}} « le corps ».

## Pluriel et accord

Le pluriel change aussi les mots qui s'accordent avec le nom. Les personnes au pluriel sont reprises par {{nda}} « eux », les choses en *-lan* par {{lan}}, etc. : {{poaa ndɔa}} « ses fils », {{diola ndɔlan}} « son nom ». Voir [Accord](../agreement.md).

!!! note "Note"
    Pour un nom absent de la Bible, on suit ces règles, mais la forme du pluriel doit être confirmée par un locuteur : plusieurs noms ont des pluriels irréguliers (on en relève une douzaine dans la description de 1979 [[(Keita1979, p. 26-29)]]).
