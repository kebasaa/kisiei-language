# Compound nouns

Kisiei forms many new nouns by combining two or more words. Eight types are distinguished [[(Keita1979, p. 31-33)]]; the Bible [[(BKG)]] makes considerable use of them for new notions.

## Types of compounds

| Type | 1979 example (respelled) | Example (Bible) | Meaning |
| --- | --- | --- | --- |
| noun + noun | {{mɔmɔtɔmndo\|r}} “fruit that monkeys love” (rice + monkey) | {{fuɲa-mamaa}} | ancestor (father + grandparent) |
| noun + verb | {{peekolaa\|r}} “well” (water + drink) | {{ɲɛdiaa}} | food (thing + eat) |
| noun + adjective | {{naasiaŋaa\|r}} “leprosy” (illness + red) | {{kɔlvesɛiyo}} | violence, wickedness (heart + dry, hard) |
| noun + verb + negation | {{tɔmcilon\|r}} “variety of maize” (monkey + see + not) | | |
| noun + referent + noun | {{kelamaɲumndan\|r}} “night-time stroll” | | |
| noun + linking word + noun | {{cɔwlabaa\|r}} “fight” (war + of + hand) | | |

The *noun + referent + noun* type corresponds to the general pattern described for Southern Kissi, where the second noun is preceded by its own class pronoun [[(Childs1995, p. 209-210)]]: in *kelamaɲumndan*, *ma* is the class pronoun of {{ɲumndan}} “night”. Southern Kissi also forms compounds from a verb or from an adjective derived from a verb [[(Childs1995, p. 211)]].

## Compounds in the Bible

The Bible creates many compounds for religious, legal or technical realities; Southern Kissi likewise names new objects with compounds [[(Childs1995, p. 210-211)]]. They are almost always written **with hyphens** between their parts:

| Compound | Parts | Meaning |
| --- | --- | --- |
| {{vana-solia-lasálàá}} | person + who offers + sacrifice | priest [Gen 41:45](https://www.bible.com/bible/1394/GEN.41.45.BKG) |
| {{fonda-loamaa-lasálàá}} | place + burn + sacrifice | altar [Gen 8:20](https://www.bible.com/bible/1394/GEN.8.20.BKG) |
| {{vana-tɛɛngaa-diom}} | person + between + word | prophet [Gen 20:7](https://www.bible.com/bible/1394/GEN.20.7.BKG) |
| {{vanaa-mangalaa-isɔɔa}} | people + … | peoples, nations [Gen 12:2](https://www.bible.com/bible/1394/GEN.12.2.BKG) |
| {{cɛi-kola}} | house + cloth | tent [Gen 9:21](https://www.bible.com/bible/1394/GEN.9.21.BKG) |
| {{fuɲa-mamaa}} | father + grandparent | ancestor [Gen 17:4](https://www.bible.com/bible/1394/GEN.17.4.BKG) |

Old and very common compounds are written **as a single word**:

| Compound | Parts | Meaning |
| --- | --- | --- |
| {{vanapɔnɔɔ}} | person + male | man |
| {{vanalanɔɔ}} | person + female | woman |
| {{vanacieo}} | person + village | human being |
| {{ɲɛdiaa}} | thing + eat | food |
| {{halataalaa}} | (God, sky) + … | heaven, sky |

!!! rule "Spelling rule"
    - A **fixed, common** compound is written as a single word ({{vanapɔnɔɔ}}).
    - A **descriptive** compound, each part of which keeps its meaning, is written with **hyphens** ({{vana-solia-lasálàá}}).
    - In the singular, the first element is in the **stem form** ({{fuɲa}}-, not *fuɲaa*-).
    - In the plural, it is the **first element** that takes the plural marking: {{vanaa-solia-lasálàá}} “the priests” [Gen 47:22](https://www.bible.com/bible/1394/GEN.47.22.BKG), {{fuɲaa-mamaa}} “ancestors” [Gen 10:32](https://www.bible.com/bible/1394/GEN.10.32.BKG); in some compounds, each element takes it: {{cɛila-kolala-toandaalan}} “tents” [Gen 13:5](https://www.bible.com/bible/1394/GEN.13.5.BKG).

In Southern Kissi too, it is the first noun, the head of the compound, that marks number through its class pronoun, and its suffix moves to the end of the compound [[(Childs1995, p. 209-210)]].

## Compound proper names

There are also compound first names made up of the birth-order name and an event linked to the birth [[(Keita1979, p. 32)]]: *Tamba lɔɔ* “Tamba born on market day”, *Saa muuloo* “Saa born during the tax period”.
