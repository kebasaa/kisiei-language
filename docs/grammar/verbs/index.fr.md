# Le verbe

Le verbe kisiei ne change pas selon la personne : c'est le pronom sujet qui indique qui agit. Ce qui varie, c'est le **radical** (forme longue ou courte, voyelle changée), le **ton**, et les petits mots qui l'entourent : auxiliaires {{co}} et {{va}}, suffixe *-nin*, particule négative {{le}} / {{te}}.

Ce chapitre décrit :

- [Radicaux et groupes](stems-and-groups.md) : forme longue et formes courtes, verbes réguliers et verbes à alternance vocalique ;
- [Temps, aspects, modes](tense-aspect-mood.md) : accompli, habituel, progressif, futur, récit, subjonctif, impératif ;
- [Négation](negation.md) : la particule finale et le radical du négatif ;
- [Verbes dérivés](derived-verbs.md) : bénéfactif, moyen, réciproque, causatif, pluriel.
