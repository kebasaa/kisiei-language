# Déterminants et quantifiants

Les déterminants se placent **après** le nom, qui prend alors sa forme radicale ; ils portent la terminaison de classe du nom (voir [Accord](../agreement.md)).

- [Adjectifs](adjectives.md) ;
- [Démonstratifs](demonstratives.md) : *ho*, *kon*, *he*, *ken*… ;
- [Possessifs](possessives.md) : *nuu*, *nɔmndo*, *ndɔɔ*… ;
- [Interrogatifs](interrogatives.md) : *nɛ̀ɛ́*, *yɛɛ*, *kuɛɛ*… ;
- [Indéfinis](indefinites.md) : *pum*, *celen*, *kpow*, *X oo X*… ;
- [Nombres](numerals.md) : cardinaux, ordinaux, accord.
