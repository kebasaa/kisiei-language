# Adjectifs qualificatifs

## Place et accord

L'adjectif qualificatif se place **après** le nom. Le nom prend sa forme radicale et l'adjectif reçoit la **terminaison de classe** du nom [[(Keita1979, p. 54-55)]] [[(Childs1995, p. 125-126)]]. Les règles et les exemples ci-dessous sont tirés des textes de la Bible en kisiei [[(BKG)]].

| Classe | Exemple | Sens |
| --- | --- | --- |
| *o* | {{pee bɛndoo}} | grand fleuve [[GEN.15.18]] |
| *o* | {{pee pɔmbɔɔ}} | petit fleuve [[GEN.15.18]] |
| personnes plur. | {{vanaa bɛndua}} | chefs, maîtres [[GEN.1.28]] |
| personnes plur. | {{navaa kɛndɛa}} | belles vaches [[GEN.41.20]] |
| *i* | {{duɲɛi bɛnduei}} | grande fête [[LEV.23.2]] |
| *i* | {{hoeyii kɛndɛi}} | bonne odeur [[GEN.8.21]] |
| *an* | {{mɛmma bɛnduan}} | grandes eaux, déluge [[GEN.6.17]] |
| *len* | {{lɛŋnde kɛndɛlen}} | bon pays [[DEU.8.7]] |
| *len* | {{yinnde bɛndulen}} | grand feu [[EXO.19.18]] |
| *lan* | {{peela bɛndulan}} / {{peela pɔmbɔlan}} | grands / petits cours d'eau [[EXO.7.19]] |
| *lan* | {{kobila bɛndulan}} | grandes villes [[GEN.41.34]] |
| plur. en *-on* | {{cieon bɛndon}} | grands villages [[NUM.32.16]] |

Le nom se met à la forme radicale décrite à la page [Classes nominales](../nouns/noun-classes.md) : radical nu dans la classe *o* ({{pee bɛndoo}}), radical + pronom de classe dans les classes *an*, *len* et *lan* ({{mɛmma bɛnduan}}, {{lɛŋnde kɛndɛlen}}, {{kobila bɛndulan}}). Le même ordre (nom + pronom de classe + adjectif + terminaison) est décrit pour le kissi du Sud [[(Childs1995, p. 150)]].

## Formes de quelques adjectifs courants

Le radical de l'adjectif reste le même ; seule la terminaison change. Sa voyelle finale se combine avec la terminaison, comme en kissi du Sud, où *bɛ̀ndù* + *-ó* donne *bɛ̀ndòó* [[(Childs1995, p. 201)]] (Bible : {{bɛndoo}}) :

| Sens | *o* | personnes plur. | *i* | *an* | *len* | *lan* | plur. *-on* |
| --- | --- | --- | --- | --- | --- | --- | --- |
| grand | {{bɛndoo}} | {{bɛndua}} | {{bɛnduei}} | {{bɛnduan}} | {{bɛndulen}} | {{bɛndulan}} | {{bɛndon}} |
| bon, beau | {{kɛndɔɔ}} | {{kɛndɛa}} | {{kɛndɛi}} | {{kɛndɛan}} | {{kɛndɛlen}} | {{kɛndɛlan}} | |
| petit | {{pɔmbɔɔ}} | {{pɔmbɔa}} | | {{pɔmbɔan}} | {{pɔmbɔlen}} | {{pɔmbɔlan}} | |
| mauvais | {{vɔɔndo}} | {{vɔɔnda}} | | | | | |

Les cases vides correspondent à des formes absentes de la Bible ; on les construit sur le même modèle, avec le statut <span class="ks-badge ks-res">Réécrit</span>.

Les adjectifs proprement dits forment une classe fermée : dimensions, couleurs, âge, qualités élémentaires [[(Childs1995, p. 126-127)]]. Beaucoup d'autres qualités s'expriment par des **verbes d'état** ou des adjectifs tirés de verbes ; voir [Radicaux et groupes](../verbs/stems-and-groups.md).

## L'adjectif employé comme nom

Précédé du pronom de classe, l'adjectif s'emploie seul, comme un nom : *o humbuo* « le blanc (celui qui est blanc) », *ma tuuvan* « le (liquide) chaud » [[(Keita1979, p. 55)]].

## Degré

### Intensité

L'intensité s'exprime :

- par l'adverbe {{taw}} « très, beaucoup » après l'adjectif ou le verbe d'état : {{dɛnɛ kɛndɔɔ taw}} « un très grand bien » [[GEN.12.16]], {{n naŋ taw}} « c'était très bon » [[GEN.1.31]] ;
- par le **redoublement** de l'adjectif, écrit avec trait d'union : {{bɛndu-bɛnduan}} « très grandes (eaux) » [[GEN.1.2]].

Le redoublement intensif est également décrit en kissi du Sud (*bɛ̀ndùbɛ́ndù* « très grand ») [[(Childs1995, p. 126)]].

### Comparaison

La comparaison se fait avec le verbe {{hiow}} « dépasser » [[(Keita1979, p. 55-56)]] :

- {{Kɛwvo ndóò hiow visia yondoa … kɔlkalu vɔɔndo ni}} « Le serpent dépassait tous les animaux sauvages en ruse » [[GEN.3.1]] ;
- {{pangele hiow vaa}} « le plus grand luminaire » [[GEN.1.16]].

Le kissi du Sud compare de la même façon avec le verbe « dépasser » ; le superlatif s'y dit « dépasser tous » [[(Childs1995, p. 283-285)]].

!!! rule "Règles d'écriture"
    - L'adjectif s'écrit **séparé** du nom : {{lɛŋnde kɛndɛlen}}, et non *lɛŋndekɛndɛlen*.
    - On n'écrit la terminaison de classe qu'une fois, sur l'adjectif : {{pee bɛndoo}}, et non *peeo bɛndoo*.
    - Les composés figés font exception et s'écrivent attachés ou avec trait d'union ; voir [Noms composés](../nouns/compounds.md).
