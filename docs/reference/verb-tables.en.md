# Verb tables

These tables summarise the forms described on the pages [Stems and groups](../grammar/verbs/stems-and-groups.md), [Tense, aspect and mood](../grammar/verbs/tense-aspect-mood.md) and [Negation](../grammar/verbs/negation.md), generally with the pronoun {{o}} “he, she”. All the combinations given are attested in the Kisiei Bible [[(BKG)]]; tone, which is not marked, distinguishes some forms that are identical in writing.
