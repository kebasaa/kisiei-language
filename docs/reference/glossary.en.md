# Glossary of grammatical terms

Terms used in this guide, with their French equivalent.

| Term | French | Definition |
| --- | --- | --- |
| **agreement** | accord | Repetition of a noun's class on the words that accompany it. See [Agreement](../grammar/agreement.md). |
| **benefactive** | bénéfactif | Derived verb showing that the action is done for someone: {{dimul}} “say to”. |
| **causative** | causatif | Derived verb meaning “make do, make be”: {{hivia}} “make pass”. |
| **circumposition** | circumposition | Preposition and postposition framing a noun: {{o}} … {{nin}} “in”. |
| **class pronoun** | pronom de classe | Pronoun that refers back to a noun according to its class: {{le}}, {{la}}, {{ma}}. |
| **class referent** | référent de classe | Class suffix repeated at the end of a relative clause: {{fula-o}}. |
| **class suffix** | terminaison de classe | End of the noun that shows its class and number: *-ndo*, *-lan*, *-len*… |
| **full form** | forme pleine | Noun with its class suffix: {{cɛiyo}}. |
| **habitual** | habituel | Aspect of habitual or general action. |
| **ideophone** | idéophone | Expressive word that depicts a sound or a manner: {{púŋ}}, {{few-few}}. |
| **long form, verbal noun** | forme longue | Form of the verb ending like a noun ({{tosaa}}), used after {{co}}, {{va}}. |
| **long vowel** | voyelle longue | Vowel pronounced for longer, written double: *aa*, *ɔɔ*. |
| **middle** | moyen | Derived verb with a reflexive or passive meaning: {{cɔmnun}} “show oneself”. |
| **noun class** | classe nominale | Group of nouns that have the same suffix and the same agreements. See [Noun classes](../grammar/nouns/noun-classes.md). |
| **particle** | particule | Small invariable word with a grammatical function: {{ni}}, {{le}}, {{yɛ}}. |
| **perfective** | accompli | Aspect that presents the action as completed: {{I tuei}} “I have heard”. |
| **postposition** | postposition | Relational word placed after the noun: {{coo}} “on”, {{nin}} “in”. |
| **progressive** | progressif | Aspect of action in progress: {{co}} / {{va}} + long form. |
| **relative clause** | relative | Clause that modifies a noun: {{lɔma ya sɔl-lan}} “the dream that I had”. |
| **stem** | radical | Part of the word that carries the meaning, without a suffix. |
| **stem form** | forme radicale | Noun without a suffix, before a determiner: {{cɛi kon}}. |
| **subjunctive** | subjonctif | Mood of purpose and wish: {{mò}} + verb. |
| **tone** | ton | Pitch of the voice on a syllable, which can change the meaning. See [Tone](../orthography/tone.md). |
