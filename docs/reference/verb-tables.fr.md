# Tableaux de verbes

Ces tableaux résument les formes décrites aux pages [Radicaux et groupes](../grammar/verbs/stems-and-groups.md), [Temps, aspects, modes](../grammar/verbs/tense-aspect-mood.md) et [Négation](../grammar/verbs/negation.md), en général avec le pronom {{o}} « il, elle ». Toutes les combinaisons données sont attestées dans la Bible en kisiei [[(BKG)]] ; le ton, non noté, distingue certaines formes identiques à l'écrit.

!!! note "Note"
    La description de 1979 donne des tableaux complets pour seize verbes, avec les six personnes [[(Keita1979, p. 96-109)]], dans l'ancienne orthographe ; la description du kissi du Sud donne les paradigmes de *cimbu* « partir » et *kiol* « mordre » [[(Childs1995, p. 220-221)]]. Les tableaux ci-dessus ne retiennent que les formes vérifiées dans la Bible.
