# Glossaire des termes grammaticaux

Termes employés dans ce guide, avec leur équivalent anglais.

| Terme | Anglais | Définition |
| --- | --- | --- |
| **accompli** | perfective | Aspect qui présente l'action comme achevée : {{I tuei}} « j'ai entendu ». |
| **accord** | agreement | Reprise de la classe d'un nom sur les mots qui l'accompagnent. Voir [Accord](../grammar/agreement.md). |
| **bénéfactif** | benefactive | Verbe dérivé indiquant que l'action est faite pour quelqu'un : {{dimul}} « dire à ». |
| **causatif** | causative | Verbe dérivé signifiant « faire faire, rendre » : {{hivia}} « faire passer ». |
| **circumposition** | circumposition | Préposition et postposition qui encadrent un nom : {{o}} … {{nin}} « dans ». |
| **classe nominale** | noun class | Groupe de noms qui ont la même terminaison et les mêmes accords. Voir [Classes nominales](../grammar/nouns/noun-classes.md). |
| **forme longue** | long form, verbal noun | Forme du verbe terminée comme un nom ({{tosaa}}), employée après {{co}}, {{va}}. |
| **forme pleine** | full form | Nom avec sa terminaison de classe : {{cɛiyo}}. |
| **forme radicale** | stem form | Nom sans terminaison, devant un déterminant : {{cɛi kon}}. |
| **habituel** | habitual | Aspect de l'action habituelle ou générale. |
| **idéophone** | ideophone | Mot expressif qui peint un son, une manière : {{púŋ}}, {{few-few}}. |
| **moyen** | middle | Verbe dérivé à sens réfléchi ou passif : {{cɔmnun}} « se montrer ». |
| **particule** | particle | Petit mot invariable à valeur grammaticale : {{ni}}, {{le}}, {{yɛ}}. |
| **postposition** | postposition | Mot de relation placé après le nom : {{coo}} « sur », {{nin}} « dans ». |
| **progressif** | progressive | Aspect de l'action en cours : {{co}} / {{va}} + forme longue. |
| **pronom de classe** | class pronoun | Pronom qui reprend un nom selon sa classe : {{le}}, {{la}}, {{ma}}. |
| **radical** | stem | Partie du mot qui porte le sens, sans terminaison. |
| **référent de classe** | class referent | Terminaison de classe reprise à la fin d'une relative : {{fula-o}}. |
| **relative** | relative clause | Proposition qui complète un nom : {{lɔma ya sɔl-lan}} « le rêve que j'ai fait ». |
| **subjonctif** | subjunctive | Mode du but et du souhait : {{mò}} + verbe. |
| **terminaison de classe** | class suffix | Fin du nom qui indique sa classe et son nombre : *-ndo*, *-lan*, *-len*… |
| **ton** | tone | Hauteur de la voix sur une syllabe, qui peut changer le sens. Voir [Tons](../orthography/tone.md). |
| **voyelle longue** | long vowel | Voyelle prononcée plus longtemps, écrite double : *aa*, *ɔɔ*. |
